# Vila Zizel design proposal

Open **index.html** in a desktop browser for the interactive concept. Resize the window or use mobile device mode to see the phone layout. The home page includes all six stays, occupancy filters, room galleries, a mobile menu and an availability request preview. Date and guest validation run locally in the tab. The concept is in English.

The **brand book** covers identity, art direction, responsive layouts, guest journey, motion and production handoff. The PDF is the presentation copy. **brand-book.html** and **brand-book.css** are the editable layout source and use the images packaged here.

- **identity/** contains outlined SVG logos, reversed variants, a transparent emblem PNG, the six stay symbols and the meander ornament.
- **assets/** contains the original generated PNGs, optimized homepage images and working copies of the repository's photography. The generated art is labeled in the prototype. Stay imagery depicts the actual accommodation.
- **previews/** contains desktop, mobile, room, inquiry and stationery previews.
- **image-prompts.md** records the two ImageGen prompts.

Room, amenity and location copy comes from the existing Vila Zizel repository. The proposal uses the property’s existing **Vila Zizel** spelling. The type stack uses system fonts, so display typography can vary by device.
